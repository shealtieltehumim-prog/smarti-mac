# Smarti AI Agent — macOS port

פותח על ידי **א.מ.ד** (Elazar) · גרסת macOS: פורט מתוך *SmartiAI Agent for Windows 0.87.0*, בכפוף לרישיון PolyForm Noncommercial 1.0.0 (שימוש לא-מסחרי בלבד — ראו `LICENSE` ו-`NOTICE.md`).

## התקנה
1. פתחו את ה-DMG וגררו את **Smarti AI Agent** לתיקיית Applications.
2. בהפעלה ראשונה: קליק ימני על האפליקציה ← **פתח** (האפליקציה אינה חתומה ב-Apple Developer ID). לחלופין בטרמינל:
   `xattr -cr "/Applications/Smarti AI Agent.app"`
3. מומלץ להעניק הרשאות ב-*הגדרות מערכת ← פרטיות ואבטחה*: **נגישות** (לשליטה במחשב), **מיקרופון** (קלט קולי), **הקלטת מסך** (צילומי מסך).

**דרישות:** macOS 13 ומעלה. צילומי מסך דורשים הרשאת *הקלטת מסך*; מקש קיצור גלובלי של המקלדת אינו זמין ב-macOS.

## בנייה מהמקור
```bash
brew install portaudio
scripts/build_macos.sh          # מפיק dist/Smarti AI Agent.app ו-DMG
```

## מה שונה מגרסת Windows
- שליטה במחשב דרך Accessibility / System Events (במקום UI Automation).
- סיסמאות ומפתחות נשמרים ב-Keychain (במקום DPAPI).
- אמון בתעודות SSL דרך Keychain של המערכת (כולל תעודות של ספקי סינון).
- התראות מערכת ו-Dock במקום Windows Toast; פח האשפה במקום סל המחזור.
- אין עדכון אוטומטי — עדכנו על ידי החלפת האפליקציה.
- חיפוש קבצים בעזרת מנוע מערכת הקבצים (אין WSearch).

## מגבלות ידועות
הפורט נכתב ונבדק בסביבת לינוקס (קומפילציה, בדיקות יחידה ובדיקת טעינה ללא תצוגה). **לא נבדק על Mac פיזי**; ייתכנו תקלות במקומות שתלויים במערכת ההפעלה.
